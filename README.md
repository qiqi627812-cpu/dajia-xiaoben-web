# 大家小本 · 完善版

基于用户提供的 REDcowork 源码继续修改，保留布面封面、翻页预览及大页面操作模式。

## 本地使用
需要 Node.js 22 或更新版本。在此目录运行：

```
npm ci
npm run build
npm run local
```

打开 http://127.0.0.1:3030 。第一次使用点击封面，设置昵称，然后添加伙伴。
本地数据保存在 `.local-data`，关闭再打开仍保留。不要删除此目录；备份时先停止服务再复制整个目录。

## 真实 AI 配置
复制 `.env.example` 为 `.env`，填写 ARK_API_KEY 和 ARK_MODEL（需要支持图片的模型才能识别小票）。密钥只在后端读取，不打包进网页。
未配置时会明确提示，并保留手动记账。测试使用本地假模型响应验证业务链路，不代表真实豆包调用验收。

## 上线
这是全栈应用，不能仅上传 static 目录来获得完整功能。
使用支持 Node.js 和 PostgreSQL 的托管环境，安装依赖、构建，设置 DATABASE_URL、ARK_API_KEY、ARK_MODEL，启动 `npm start`。启动会自动执行增量迁移。
当前是单账本共享演示模型，没有多用户账号隔离。公开展示时使用演示数据；实际私密使用应由托管平台增加访问控制。
本目录没有原平台的数据库数据，只有结构迁移；不包含密钥。

## 已修复
- AI 参与人编号初始化、类别与明示汇率传递；明确的新人物自动建立并提示。
- 信息完整且置信度足够时自动入账，可关闭；有警告时进入核对表单。
- 服务端校验成员、金额、汇率；幂等入账；自定义分摊保留稳定成员编号。
- 按成员编号统计，改名不拆账；历史记录显示原始昵称快照。
- 整数分摊与精确十进制折算；最大余数保证折算分摊总和守恒。
- 历史汇率快照用于明细和统一结算；原币种转账记录和撤销。
- 汇率请求切换币种后的过期结果丢弃；手动值不被覆盖。
- 新增成员保存手绘头像；成员卡、仪表盘、输入控件与玻璃导航重新排版。

## 验证
`npm test` 执行金额单元测试和独立临时数据库接口集成测试；不会改动 `.local-data`。
集成测试内的模型及汇率服务为明确的本地测试替身，不产生 AI 费用。
真实模型性能和小票准确率仍需配置你的密钥后验证。
